# Hồ sơ khách hàng

- Thứ tự: 21
- Trạng thái: Chưa làm
- Module: customers
- Database: `database/customers.md`

## API

`GET|POST /api/v1/customers`, `GET|PATCH|DELETE /api/v1/customers/:id`

Xem dùng `orders.view`. Ghi dùng `orders.update`. Tìm kiếm và phân trang.

## Ngoài phạm vi

Địa chỉ. Lịch sử mua hàng.
