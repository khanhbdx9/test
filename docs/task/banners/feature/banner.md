# Banner

- Thứ tự: 20
- Trạng thái: Xong
- Module: banners
- Database: `database/banners.md`

## API

- Admin: `GET|POST /api/v1/banners`, `GET|PATCH|DELETE /api/v1/banners/:id`
- Public (gom controller khách): `GET /api/v1/public/banners` — banner đang hoạt động trong khoảng thời gian

Quyền `banners.view` và `banners.manage`.
